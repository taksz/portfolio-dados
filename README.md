## Projetos

1. **[analise-vendas](analise-vendas/)** — Análise de vendas de e-commerce: geração de dataset, carga em SQL (SQLite), consultas de negócio, análise exploratória com pandas e gráficos, comparação com dados reais do IBGE (API SIDRA) e dashboard em Power BI. [Ver README do projeto](analise-vendas/README.md).
2. **[encurtador-url](encurtador-url/)** — API (FastAPI) de encurtador de URL com analytics: cliques por dia, navegador, sistema operacional e origem, com dashboard. [Ver README do projeto](encurtador-url/README.md).
3. **[rastreador-precos](rastreador-precos/)** — Robô de automação que monitora preços (web scraping), guarda o histórico em SQLite, alerta quando o preço cai abaixo de um limite e gera gráficos de evolução. [Ver README do projeto](rastreador-precos/README.md).
